SMS Verification

The code arrives at the number typed into the form and confirms that the number belongs to the person registering. The same number is used later for password recovery and for any security check the platform runs. If the code takes long, work through the list before requesting it again.

  • wait for the resend timer to finish;
  • check that the number was typed without a mistake;
  • make sure the phone has signal and no app is blocking SMS;
  • request a fresh code and type it without spaces;
  • never pass the code to anyone, including callers who claim to be support.

Mistakes That Cause Problems Later

Each of these looks harmless at sign-up and turns into a blocked withdrawal or a locked account months later.

  • registering with a friend's or a temporary number;
  • entering a nickname instead of the real name;
  • opening a second account after losing the password;
  • sharing SMS codes with anyone;
  • using a VPN that changes the country during sign-up.
