Installation on Android

The whole process takes a minute or two; Android asks once for permission to install from a source other than Google Play.

  1. Open the download link on the phone and save the file;
  2. Allow installation from this source when Android prompts (Settings > Apps > Special app access > Install unknown apps);
  3. Open the file from the notification or the Downloads folder and tap Install;
  4. Launch NK101 and log in with the username and password;
  5. Switch "Install unknown apps" back off once the app is in place.
