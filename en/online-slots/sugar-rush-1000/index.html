Base Game: Clusters and Tumbles

Forty-nine candies drop onto the 7x7 grid. Any group of five or more identical symbols that touch sideways or vertically pays out, then disappears; new symbols tumble into the gaps and can form the next cluster. The sequence ends when no new cluster appears. There are no paylines and no wild, so the payout depends only on the symbol and the size of the cluster.

Multiplier Spots With an Example

Each position where a winning symbol is removed is marked. The second removal from the same position creates a x2 multiplier, and every further removal doubles it: x4, x8, x16 and so on up to x1,024. A cluster covering marked spots is multiplied, and when it covers several spots their values are added. In the base game the marks clear on the next spin; in free spins they stay until the bonus ends.

Example: a cluster of five round sweets pays 1x the bet. The same cluster sitting on a x4 spot pays 4x. If it also covers a neighbouring x2 spot, the multipliers add up to x6 and the cluster pays 6x.
